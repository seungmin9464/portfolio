# Portfolio

**사용자 경험과 코드의 완성도를 함께 고민하는 프론트엔드 개발자의 포트폴리오입니다.**

웹 퍼블리싱 경험을 바탕으로 UI 구현 역량을 쌓아왔으며, 현재는 React와 Next.js를 활용해 컴포넌트 설계와 웹 애플리케이션 개발 역량을 확장하고 있습니다.

단순히 화면을 구현하는 것을 넘어, 유지보수하기 좋은 코드와 사용하기 편리한 인터페이스를 만드는 것을 목표로 합니다.

## Tech Stack

| Category | Technology |
|---|---|
| Framework | Next.js 16 |
| Library | React 19 |
| Language | TypeScript |
| Styling | CSS |
| Code Quality | ESLint |

## Project Overview

개인 프로젝트와 개발 경험을 소개하기 위해 제작한 포트폴리오 웹사이트입니다.

**개발 목표**
- 프로젝트와 기술 역량을 명확하게 전달하는 UI 구성
- 재사용성과 유지보수성을 고려한 컴포넌트 설계
- 다양한 화면 크기를 고려한 반응형 웹 구현
- 사용자 경험을 고려한 직관적인 인터페이스 구성

## Project Structure

## Getting Started

```bash
git clone https://github.com/seungmin9464/portfolio.git

cd portfolio/project/frontend

npm install

npm run dev
```

개발 서버 실행 후 `http://localhost:3000`에서 확인할 수 있습니다.

## Development Focus

**사용자 중심의 UI**

사용자가 정보를 쉽게 탐색하고 이해할 수 있도록 화면 구성과 인터랙션을 고민합니다.

**재사용 가능한 코드**

반복되는 UI를 컴포넌트 단위로 관리하고, 기능 확장과 유지보수를 고려한 구조를 지향합니다.

**지속적인 개선**

새로운 기술을 학습하고 실제 프로젝트에 적용하며, 코드의 품질과 개발 생산성을 높이기 위해 노력합니다.
